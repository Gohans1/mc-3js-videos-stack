# Cài đặt

## Công cụ và Tài nguyên

| Mục                        | Nội dung                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cài một phát               | Cài Bun rồi chạy bun run setup tại thư mục gốc: nó chạy bun install, setup:vault rồi link. setup:vault liệt kê mọi công cụ còn thiếu kèm lệnh cài, dừng nếu thiếu curl hoặc ffmpeg. Kho nặng motion, packs, tools không tải được nên chép từ máy cũ, thiếu thì setup dừng trước link và chỉ rõ.                                                                                                       |
| Gói âm thanh               | bun run pack:sound gói mọi âm vào một zip theo đúng đường dẫn vault, máy mới chạy bun run setup --sound-zip <zip hoặc link Drive> thay cho mấy giờ torrent, category và SOURCES.json về đúng chỗ. Link chỉ đưa lúc chạy, không ghi vào repo; link private thì tải zip bằng trình duyệt rồi đưa đường dẫn. Giữ zip riêng tư vì giấy phép Sonniss cấm chia sẻ và âm Mojang không phải của mình.         |
| Công cụ gốc                | Cài Bun, Node 22, Python 3, FFmpeg kèm ffprobe, curl rồi chạy bun install tại thư mục gốc trên Windows. Python của phim ưu tiên .venv trong thư mục phim, dò nhịp cần uv pip install -r scripts/sound/requirements.txt, còn đổi tốc độ hoặc cao độ cần Rubber Band CLI.                                                                                                                               |
| Kho tài nguyên             | Chạy bun run setup:vault để tải tài nguyên nhẹ theo scripts/vault-assets.json và scripts/sfx-catalogue.json có kiểm mã băm và định dạng WAV. Tài nguyên nặng nằm tại externalRoot của vault.json, mặc định E:/mc_vault hoặc đổi qua MC_VAULT_EXTERNAL.                                                                                                                                                |
| Kho âm thanh và tham chiếu | Chạy bun run setup:sound để dựng kho tệp WAV chuẩn vào vault/sound/bgm và vault/sound/sfx kèm vault/sound/SOURCES.json. Pack torrent Sonniss tải riêng bằng bun run fetch:sound-raw (cần aria2, chạy hàng giờ, dừng lúc nào cũng được); dòng Waiting for you cuối mỗi lệnh chỉ thứ phải tải tay. Bộ ảnh đối chiếu giao diện CapCut 9.7 và danh mục nằm gọn tại vault/references/capcut/manifest.json. |
| Kho âm thanh Minecraft     | Chạy bun run setup:mc-sound để dựng externalRoot/mc-sound từ Minecraft gốc và các pack trong scripts/mc-sound-packs.json, có kiểm SHA1 và PEAKS.json. setup:vault tự gọi bước này khi externalRoot đã có.                                                                                                                                                                                             |
| Tai nghe cho AI (earshot)  | CLI riêng giấy phép MIT (github.com/Leonxlnx/earshot), mã nguồn để tại externalRoot/tools/earshot, cài bằng uv pip install -e vào một venv riêng rồi đưa lệnh earshot lên PATH. Đặt EARSHOT_HOME sang ổ lớn vì model chừng 1.1 GB, chạy earshot doctor để kiểm gói, ffmpeg và model.                                                                                                                  |
| Nối vào phim               | Chạy bun run link để nối vault vào mọi phim và dựng picked.zip, hoặc bun run link ten-phim cho một phim; lệnh không cài dependency hay tải tài nguyên. Trình duyệt xuất hình lấy từ khóa live-studio.chrome trong package.json của phim. |
| Phim mới | Sau khi setup thành công, chạy bun run new-film ten-phim tại gốc; lệnh tự cài dependency, nối vault và dựng picks. Vào films/ten-phim chạy bun run check rồi bun run studio, mở URL được in và kiểm tra cảnh. |
| Khôi phục tạo phim | Nếu phim đã được sao nhưng bước sau lỗi, giữ thư mục và chạy bun packages/live-studio/init.mjs films/ten-phim rồi bun run link ten-phim tại gốc. init.mjs chỉ nối Studio và cài dependency; không tải vault hay dựng picks. |

## Bản quyền và Lời dẫn

| Mục       | Nội dung                                                                                                                                                                                                                                                                        |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bản quyền | Thư mục vault bị Git bỏ qua nên tài sản của Mojang, Mixamo và Mixkit không đi kèm mã nguồn. Giấy phép rig ghi tại packages/mc-actor/assets/CREDITS_CC_BY.txt, còn nguồn WAV ghi tại vault/sound/SOURCES.json và sound/sfx/SOURCES.json.                                         |
| Lời dẫn   | Sinh take vào voice/takes và bản thử voice/try bằng scripts/voice/gen.ts, ghép full_voice.wav kèm Phrase Bricks bằng scripts/voice/assemble.ts, và lấy mốc từ bằng scripts/voice/cues.ts. Take chưa có mốc từ thì bun run voice:align căn bằng whisperX, mix.py chỉ cần ffmpeg. |
| whisperX  | Tạo venv Python 3.10 đến 3.13 bằng uv venv rồi uv pip install whisperx (3.8.6 kèm torch 2.8, GPU cần CUDA 12.8). Đặt WHISPERX_PYTHON trỏ tới python của venv đó, model large-v3 tải lần đầu vào HF_HOME.                                                                        |
