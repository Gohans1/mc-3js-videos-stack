# Cài đặt

## Công cụ và Tài nguyên

| Mục                        | Nội dung                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cài một phát               | Cài Bun rồi chạy bun run setup tại thư mục gốc: nó chạy bun install, setup:vault rồi link. setup:vault liệt kê mọi công cụ còn thiếu kèm lệnh cài, dừng nếu thiếu curl hoặc ffmpeg. Kho nặng motion, packs, tools không tải được nên chép từ máy cũ, thiếu thì setup dừng trước link và chỉ rõ.                                                                                                       |
| Gói âm thanh               | bun run pack:sound gói mọi âm vào một zip theo đúng đường dẫn vault, máy mới chạy bun run setup --sound-zip <zip hoặc link Drive> thay cho mấy giờ torrent, category và SOURCES.json về đúng chỗ. Link chỉ đưa lúc chạy, không ghi vào repo; link private thì tải zip bằng trình duyệt rồi đưa đường dẫn. Giữ zip riêng tư vì giấy phép Sonniss cấm chia sẻ và âm Mojang không phải của mình.         |
| Công cụ gốc                | Cài Git for Windows từ 2.54 trở lên, Bun, Node 22, Python 3, FFmpeg kèm ffprobe, curl rồi chạy bun install tại thư mục gốc trên Windows. Python của phim ưu tiên .venv trong thư mục phim, dò nhịp cần uv pip install -r scripts/sound/requirements.txt, còn đổi tốc độ hoặc cao độ cần Rubber Band CLI.                                                                                                                               |
| Kho tài nguyên | Asset và code nằm thật trong vault/ trên C:, không tạo junction hay symlink; bun run setup:vault tải phần có nguồn đã ghim. externalRoot trong vault.json chỉ dành cho sound-raw, gói tải gốc và backup trên E:, đổi bằng MC_VAULT_EXTERNAL. |
| Kho âm thanh và tham chiếu | Chạy bun run setup:sound để dựng kho tệp WAV chuẩn vào vault/sound/bgm và vault/sound/sfx kèm vault/sound/SOURCES.json. Pack torrent Sonniss tải riêng bằng bun run fetch:sound-raw (cần aria2, chạy hàng giờ, dừng lúc nào cũng được); dòng Waiting for you cuối mỗi lệnh chỉ thứ phải tải tay. Bộ ảnh đối chiếu giao diện CapCut 9.7 và danh mục nằm gọn tại vault/references/capcut/manifest.json. |
| Kho âm thanh Minecraft | bun run setup:mc-sound dựng vault/mc-sound thật trên C: từ Minecraft và scripts/mc-sound-packs.json, có kiểm SHA1 và PEAKS.json. setup:vault tự gọi hoặc khôi phục từ gói âm thanh. |
| Tai nghe cho AI (earshot) | CLI MIT (github.com/Leonxlnx/earshot): source tại vault/tools/earshot, cài bằng uv pip install -e trong venv riêng và đưa earshot lên PATH. Đặt EARSHOT_HOME tại vault/tools/earshot-home-win trên C:, chạy earshot doctor để kiểm gói, ffmpeg và model. |
| Dò cảnh tham khảo | PySceneDetect 0.7.3, BSD-3-Clause, CPU và không tải model: tại root chạy uv venv --python 3.12 .venv nếu chưa có, rồi uv pip install --python .venv/Scripts/python.exe -r scripts/review/requirements.txt. bun run scenes <video> chạy ở root hoặc phim; SCENEDETECT_PYTHON chọn Python khác, bun run scenes --help nêu đầu ra và giới hạn thời gian. |
| Hộp công cụ media local | bun run media list và doctor liệt kê công cụ cùng phiên bản; setup <tool> cài môi trường riêng hoặc binary Windows đã pin SHA-256, không thay Python/earshot đang dùng. Cache tại vault/tools/media, MC_MEDIA_HOME đổi vị trí; mỗi run giữ bằng chứng và có timeout, help từng tool và core --ref sound/review nêu cách dùng. |
| Build model âm local | media setup caption --minutes 20 cần CMake và MinGW để build fork llama.cpp CPU; build/cache giữ lại để chạy tiếp nếu hết giờ. Caption/vision nhỏ có thể bịa nội dung; chưa xác minh không biến thành nhãn chuẩn, Kokoro chưa có voice Việt và giữ notices eSpeak-ng GPL riêng. |
| Nối vào phim | bun run link sao file thật từ vault vào assets/public của mọi phim và dựng picked.zip; thêm tên phim để chỉ chuẩn bị một phim. Chạy lại cập nhật bản sao chưa chỉnh riêng, từ chối ghi đè file đã sửa; không tải asset hay cài dependency. |
| Worktree Windows | Chỉ giữ link dependency do Bun quản lý; xem hướng dẫn dọn WT trong bun run skills get core --ref film. Trước khi xoá WT, gỡ mọi junction/link lồng bằng thao tác không đệ quy; Git cũ có thể xoá cả đích link, kể cả cùng ổ C:. |
| Vault chung cho worktree | Đặt MC_VAULT_ROOT trỏ tới vault thật của checkout chính để CLI Bun đọc chung asset và đổi đích lệnh quản lý vault; vault.json riêng và soundVault của phim vẫn ưu tiên. Không thay đổi biến này khi đang chạy tác vụ ghi vault. |
| Tìm asset theo nghĩa | bun run find trả BM25 rồi OpenFilm semantic riêng, không cần key hay build index; --offline chỉ đọc cache, --json cho AI. Index Gemini đã chuẩn bị vẫn dùng riêng qua --semantic; đọc bun run skills get core --ref sound trước khi gửi media hoặc câu mới. |
| Giữ index và ngân sách | MC_SEMANTIC_DB và MC_SEMANTIC_MANIFEST nối build/find với dữ liệu dùng chung; MC_SEMANTIC_QUOTA_DB giữ bộ đếm ngoài worktree. MC_SEMANTIC_DAILY_LIMIT là ngân sách nội bộ theo ngày Pacific, không tăng hay xác nhận quota Google. |
| Phim mới | Sau khi setup thành công, chạy bun run new-film ten-phim tại gốc; lệnh tự cài dependency, nối vault và dựng picks. Vào films/ten-phim chạy bun run check rồi bun run studio, mở URL được in và kiểm tra cảnh. |
| Khôi phục tạo phim | Nếu phim đã được sao nhưng bước sau lỗi, giữ thư mục và chạy bun packages/live-studio/init.mjs films/ten-phim rồi bun run link ten-phim tại gốc. init.mjs chỉ nối Studio và cài dependency; không tải vault hay dựng picks. |

## Công cụ media mở rộng

| Mục | Cách dùng |
| --- | --- |
| Tracking CPU | media setup tapir hoặc media setup track cài môi trường Torch CPU và checkpoint đã pin/hash; --frames giới hạn số frame giữ trong RAM, --minutes giới hạn thời gian. |
| Kho âm tùy chọn | media setup foley cài alpha Foley cùng PANNs đã kiểm hash; TOML chỉ rõ library.root và storage.data_dir ngoài kho, CLAP tải lần đầu vào cache riêng. |
| Metadata âm | media setup metadata cài BWF MetaEdit Windows và notices trong archive; adapter chỉ đọc/export XML, không sửa WAV. |
| Cache và quyền dùng | Giữ vault/tools/media và bằng chứng run-* khi chuyển checkout; không di chuyển venv vì launcher có thể chứa đường dẫn cũ, cài lại bằng setup và dùng cache uv. |

## Bản quyền tài nguyên và lời dẫn

| Mục       | Nội dung                                                                                                                                                                                                                                                                        |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bản quyền | Thư mục vault bị Git bỏ qua nên tài sản của Mojang, Mixamo và Mixkit không đi kèm mã nguồn. Giấy phép rig ghi tại packages/mc-actor/assets/CREDITS_CC_BY.txt, còn nguồn WAV ghi tại vault/sound/SOURCES.json và sound/sfx/SOURCES.json.                                         |
| Lời dẫn   | Sinh take vào voice/takes và bản thử voice/try bằng scripts/voice/gen.ts, ghép full_voice.wav kèm Phrase Bricks bằng scripts/voice/assemble.ts, và lấy mốc từ bằng scripts/voice/cues.ts. Take chưa có mốc từ thì bun run voice:align căn bằng whisperX, mix.py chỉ cần ffmpeg. |
| whisperX  | Tạo venv Python 3.10 đến 3.13 bằng uv venv rồi uv pip install whisperx (3.8.6 kèm torch 2.8, GPU cần CUDA 12.8). Đặt WHISPERX_PYTHON trỏ tới python của venv đó, model large-v3 tải lần đầu vào HF_HOME.                                                                        |
