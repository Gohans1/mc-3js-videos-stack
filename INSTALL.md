# Installation

## Tools and assets

| Task                                     | Command and requirements                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Set up a machine                         | Install Bun and run bun run setup from the repo root. It runs bun install, setup:vault, then link. setup:vault lists missing tools with install commands and stops if curl or FFmpeg is missing. Copy the motion, packs, and tools vault directories from the old machine. Setup reports missing directories before linking.                                                                                           |
| Restore the sound archive                | Run bun run pack:sound to save audio, categories, and SOURCES.json at their vault paths. On the new machine, run bun run setup --sound-zip <zip-or-Drive-link>. Pass the link only at runtime, or download a private link in the browser and pass the file path. Keep the ZIP private because it contains restricted Sonniss and Mojang assets.                                                                        |
| Base tools                               | On Windows, install Git for Windows 2.54 or later, Bun, Node 22, Python 3, FFmpeg with ffprobe, and curl. Run bun install from the root. Film tools prefer a .venv in the film folder. Install beat detection with uv pip install -r scripts/sound/requirements.txt. Use the Rubber Band CLI for tempo or pitch changes.                                                                                               |
| Asset vault                              | Keep asset and code files physically in vault/ on C: and avoid junctions and symlinks. bun run setup:vault downloads assets with pinned sources. Optional reusable props live in vault/props/, and find caches pack/jar inspection lazily in vault/cache/mc-catalog.v1.json. Use externalRoot in vault.json only for sound-raw, original downloads, and backups on E:. Override it with MC_VAULT_EXTERNAL.             |
| Sound and reference libraries            | Run bun run setup:sound to build the WAV library in vault/sound/bgm and vault/sound/sfx with vault/sound/SOURCES.json. Use bun run fetch:sound-raw for the Sonniss torrents. It requires aria2, can run for hours, and can be stopped. The Waiting for you section lists manual downloads. The CapCut 9.7 interface references and catalog are in vault/references/capcut/manifest.json.                               |
| Minecraft sounds                         | bun run setup:mc-sound builds vault/mc-sound on C: from Minecraft and scripts/mc-sound-packs.json. It verifies SHA1 and writes PEAKS.json. setup:vault runs it or restores it from the sound archive.                                                                                                                                                                                                                  |
| Earshot                                  | The MIT CLI source (github.com/Leonxlnx/earshot) lives at vault/tools/earshot. Run uv pip install -e . in a dedicated environment and add earshot to PATH. Set EARSHOT_HOME to vault/tools/earshot-home-win on C: and run earshot doctor to check packages, FFmpeg, and models.                                                                                                                                        |
| Detect cuts in reference footage         | PySceneDetect 0.7.3 uses the CPU without a model download and is licensed under BSD-3-Clause. From the root, run uv venv --python 3.12 .venv if needed, then uv pip install --python .venv/Scripts/python.exe -r scripts/review/requirements.txt. Run bun run scenes <video> from the root or a film. Set SCENEDETECT_PYTHON to choose another interpreter, and use bun run scenes --help for outputs and time limits. |
| Local media tools                        | Run bun run media list or bun run media doctor to see tools and versions. media setup <tool> installs an isolated environment or a SHA-256-pinned Windows binary without changing the current Python or Earshot installation. The cache defaults to vault/tools/media. Set MC_MEDIA_HOME to move it. Runs retain evidence and have a timeout. Read tool help and core --ref sound or --ref review for usage.           |
| Bundled FFmpeg and QC adapters           | media ffmpeg uses MIT scripts and templates from ffmpeg-skill 3.10.1. media qc uses qc-skill 1.4.0. Their source hashes are pinned under third-party, and the adapters install no skill, MCP server, model, or npm dependency. They require Python and FFmpeg/ffprobe. FFmpeg 9.0.2 was verified on the development machine. Check the binary's license separately from the adapter's MIT license.                     |
| Âm thanh 3D và reverb | Mix offline dùng NumPy và SciPy. Cài bằng uv pip install -r scripts/sound/requirements.txt hoặc uv pip install numpy scipy. |
| FFmpeg version                           | The mixer requires FFmpeg 7.0 or later to read its filter graph from a file. Choose a patched release. Filter graph syntax was verified with 8.1.1 and 9.0.2.                                                                                                                                                                                                                                                          |
| Build local caption models               | media setup caption --minutes 20 requires CMake and MinGW to build the CPU llama.cpp fork. It keeps the build and cache for a later attempt if the job times out. Verify results from small caption or vision models before using them as labels. Kokoro has no Vietnamese voice. Keep the eSpeak-ng GPL notices separate.                                                                                             |
| Prepare film assets                      | bun run link copies real files from the vault into each film's assets/public and builds picked.zip. Pass a film name to prepare one film. Reruns update unchanged copies and refuse to overwrite modified files. The command does not download assets or install dependencies.                                                                                                                                         |
| Windows worktrees                        | Keep only dependency links managed by Bun. See bun run skills get core --ref film for cleanup steps. Remove nested junctions or links non-recursively before deleting the worktree. Older Git can delete the link target even when it is on the same C: drive.                                                                                                                                                         |
| Share the vault with worktrees           | Set MC_VAULT_ROOT to the main checkout's vault so Bun commands share assets and vault-management commands write to that location. A separate vault.json and the film's soundVault still take precedence. Keep the variable fixed while a job writes to the vault.                                                                                                                                                      |
| Find assets by meaning                   | bun run find returns BM25 and separate OpenFilm semantic results without a key or a local index build. Use --offline for cached results and --json for structured output. Use --semantic for the separate Gemini index if prepared. Read bun run skills get core --ref sound before sending media or a new query.                                                                                                      |
| Share the search index and quota counter | MC_SEMANTIC_DB and MC_SEMANTIC_MANIFEST link build and find to shared data. MC_SEMANTIC_QUOTA_DB keeps the counter outside the worktree. MC_SEMANTIC_DAILY_LIMIT sets the local budget by Pacific day. It does not change or confirm the Google quota.                                                                                                                                                                 |
| Create a film                            | After setup, run bun run new-film my-film from the root. It installs dependencies, connects the vault, and builds picks. In films/my-film, run bun run check and bun run studio, then open the printed URL and inspect the scene.                                                                                                                                                                                      |
| Recover an incomplete film setup         | Keep the copied film folder if a later step fails. From the root, run bun packages/live-studio/init.mjs films/my-film, then bun run link my-film. init.mjs connects Studio and installs dependencies. Use link to prepare picks and setup:vault for vault downloads.                                                                                                                                                   |

## Additional media tools

| Task                     | How to run it                                                                                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CPU tracking             | Run media setup tapir or media setup track to install a CPU Torch environment and a checksum-pinned checkpoint. Use --frames to cap the frames kept in memory and --minutes to cap runtime. |
| Optional sound library   | media setup foley installs alpha Foley and checksum-verified PANNs. Set library.root and storage.data_dir outside the repo in TOML. CLAP downloads to its own cache on first use.           |
| Audio metadata           | media setup metadata installs BWF MetaEdit for Windows and keeps notices in the archive. The adapter reads metadata and exports XML without editing WAV files.                              |
| Move to another checkout | Keep vault/tools/media and run-* evidence. Reinstall the virtual environment with setup and reuse the uv cache. A moved virtual environment can retain old paths in its launcher.           |

## Asset licenses and narration

| Task                      | Command and requirements                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenFilm library          | Use bun run find with --source openfilm to find and inspect imported assets. Run bun run asset --help for placement and editing. Studio groups them in Audio, Text, Transitions, Adjustment, and Effects. bun run pack:sound keeps source files, WAVs, categories, and licenses at their vault paths. On another machine, pass the downloaded private ZIP to bun run setup --sound-zip.                        |
| Inspect a reference video | bun run reference inspect uses Python 3.11+ and FFmpeg for frames and captions. URLs require yt-dlp and a supported JavaScript runtime. Inspection does not download models or call an external AI provider. study and compare use the pinned measure.mjs from openfilm/skill-replicate with its MIT LICENSE and upstream.json. Check input-video rights separately. See bun run skills get core --ref review. |

| Topic     | Details                                                                                                                                                                                                                                                                                              |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Copyright | Git ignores the vault, so the source repo does not ship Mojang, Mixamo, or Mixkit assets. Rig credits are in packages/mc-actor/assets/CREDITS_CC_BY.txt. WAV sources are in vault/sound/SOURCES.json and sound/sfx/SOURCES.json.                                                                     |
| Narration | scripts/voice/gen.ts writes takes to voice/takes and auditions to voice/try. scripts/voice/assemble.ts assembles full_voice.wav and Phrase Bricks. scripts/voice/cues.ts reports word times. Run bun run voice:align with whisperX for takes missing word times. mix.py needs only FFmpeg.           |
| whisperX  | Create a Python 3.10 to 3.13 environment with uv venv and install whisperx with uv pip install whisperx. The verified setup uses whisperX 3.8.6 with Torch 2.8 and CUDA 12.8 for GPU. Point WHISPERX_PYTHON to that environment's interpreter. The large-v3 model downloads to HF_HOME on first use. |
| Lip sync  | Extract Rhubarb Lip Sync (MIT, github.com/DanielSWolf/rhubarb-lip-sync/releases) to vault/tools/Rhubarb-Lip-Sync-<version>-<platform>/ or point RHUBARB to the executable. bun run voice:lips uses it with FFmpeg.                                                                                   |
