# Film Capability Atlas

Read this once when starting a new film. Every tool, workspace package export, procedural acting rig, shader hook, asset library, and repo skill available inside `films/<name>/` is indexed below so you never miss a hidden capability or reinvent an existing module. Package sources live under `packages/<pkg>/src/*.ts` (e.g. `packages/film-stage/src/camera.ts`, `packages/mc-actor/src/player.ts`) and full timeline schemas in `skill-data/core/references/contract.md`. Keep `draw(t)` pure and seek-independent; treat Studio and built-in timelines as a starting pad, never a ceiling.
