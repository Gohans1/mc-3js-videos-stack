# Minecraft 3D Video Architecture & Assets Guide

## Setup
- không tải trực tiếp các folder/file nặng như .jar, full modpack,etc... vào thẳng project. Lưu bọn minecraft assets nặng gốc đã tải về ở khu riêng biệt trong máy để các project dùng chung
- Khi Project cần đạo cụ/assets/ảnh/nhân vật/sự vật/mô hình/etc... Cụ thể nào trong đống đó thì hãy chỉ kéo riêng mình nó về dùng vào `pack/` 

Dùng symlink nối kho gốc với project (nhớ gitignore)
- <vault_path>/jar     -> assets/public/mc
- <vault_path>/mcasset -> assets/public/mcasset
- <vault_path>/mcprep  -> assets/public/rig
- <vault_path>/motion  -> assets/public/motion
- <vault_path>/packs: kho gói mod/resource pack đã lọc (không symlink vào project; chỉ cherry-pick file cần dùng vào `pack/`)

- Nếu đã setup thì có thể bỏ qua bước này

## Using
- Tìm và cho dev xem mẫu 3-6 variants mà m cho là hợp lý nhất

## Repo

### [block-model-renderer](https://github.com/ewanhowell5195/block-model-renderer)
- Vai trò: Dựng toàn bộ thế giới khối tĩnh, tường nhà, địa hình, bàn ghế, đồ đạc và đạo cụ nội thất.
- Điểm mạnh: Đọc trực tiếp định dạng Block JSON chuẩn (elements, from, to, faces). Tự động tính culling khử mặt khuất, gộp lưới tối ưu hóa draw call và đổ bóng chuẩn từng điểm ảnh.

### [MineRender](https://github.com/InventivetalentDev/MineRender)
- Vai trò: Vẽ giao diện 2D, phông chữ pixel Minecraft và hoạt ảnh động vật sống.
- Điểm mạnh:
  - GuiObject: In chữ pixel chuẩn game (ví dụ nhãn camera an ninh, phụ đề, mã phòng) và các bảng giao diện hotbar, thanh máu lên lớp phủ 2D.
  - EntityObject: Chứa sẵn toàn bộ mô hình sinh vật trích xuất từ Java code kèm xương và hoạt ảnh bước chân (walk cycle) tự nhiên khớp với trục thời gian.

### [MCprep](https://github.com/Moo-Ack-Productions/MCprep) (player.glb)
- Vai trò: Diễn viên người chơi chính (Steve, Alex hoặc skin tùy biến).
- Điểm mạnh: Khớp uốn cong khuỷu tay và đầu gối 90 độ mượt mà không rách lưới, có sẵn hệ thống xương điều khiển mắt, miệng và cử chỉ ngón tay.
- Ghi nhận quyền tác giả: BoxScape Studios và TheDuckCow theo giấy phép CC-BY 3.0.
- Cử động người thật: lấy clip UAL1/UAL2 (thiếu thì Mixamo), chép sang Steve theo VỊ TRÍ khớp (không chép góc xoay từ tư thế gốc: ra gù, xoắn chân), rồi cho qua khoá chân + IK; không dùng video -> chuyển động.

### Luật lọc gói (rút ra từ đợt lọc)
- Đánh giá bằng mắt trên ảnh render và bằng tai, không theo tên hay lượt tải.
- Loại: All Rights Reserved, giấy phép custom cấm dùng lại assets (Create, Supplementaries, Abnormals, Botania...), và gói cấm riêng âm thanh.
- Tag giấy phép Modrinth có thể sai: gói nhạc/âm thanh "MIT/CC0" mà repack nhạc game khác (Terraria, Skyrim, Half-Life, Minecraft Dungeons/Story Mode/Legends, C418 chưa phát hành, Taco Bell, Cookie Clicker, Overwatch) là loại ngay: dính Content ID.
- Mob, hạt, hiệu ứng, thời tiết của mod thường là code Java: không lấy ra được. Lấy được: block/item JSON (bmr render thẳng), .geo.json (GeckoLib, cần loader riêng), .bbmodel (cần Blockbench xuất glb), .obj (OBJLoader), .ogg.
- Render ra ô tím-đen = thiếu texture (thường là model viết cho mod khác, hoặc model .obj/.geo mà bmr không đọc). "Không ra hình" = block vẽ bằng code (block entity, chất lỏng) hoặc lỗi model.
- Danh sách gói đã loại kèm lý do: `<vault_path>/packs_triage.md`. Đừng tải lại các gói đó.
- Xem trước cả kho trên máy này: `C:\Users\ADMIN\Desktop\mc-asset-browser` (`bun server.ts`, cổng 4340): lưới ảnh, nghe âm thanh, xoay 3D, ♥ yêu thích lưu ở `<vault_path>/favorites.json`.
