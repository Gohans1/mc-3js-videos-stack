# channel-dna Factory Architecture

Canonical engineering reference for the channel-dna source modules, corpus storage layout, strict `schema_version: 1 | 2 | 3` JSON contracts, `statsVersion: 4` deterministic aggregation, and atomic zero-data-loss checkpointing. Every command runs through `scripts/cli.ts` (or standalone `scripts/gemini-api.ts`) via `bun` from the repository root.

## Source Modules

| Path | Responsibility |
| --- | --- |

| `scripts/mine.ts` | Runs resumable parallel multimodal extraction (`--backend aistudio` up to 2 tabs, or `--backend gemini-api` up to 4 workers), enforces pre-flight 1M token budget (`resolveMiningFps` + `--auto-fps`, setting `miningMode: "micro_24fps" | "macro_lowfps"`), caps longform `macro_lowfps` downloads at 720p and downsamples burned copies via `macroOutputFps` while preserving native `sourceFps`, clamping post-burn `encodedFps`, omitting `f<n>` prompts when no frame counter is burned, and scaling download timeouts by duration, attaches browse thumbnail automatically on non-Shorts `/videos` (`shouldAttachThumbnail` + `resolveThumbnailCandidates` YouTube CDN fallback `maxresdefault -> sddefault -> hqdefault` + `expectThumbnail` fail-closed), burns atomic 720p timecode bars while probing `hasAudioStream`, `durationSec`, `sourceFps`, `sourceWidth`/`sourceHeight`, and 10 Hz FFmpeg `ebur128` + `silencedetect=d=0.15` (`I`, `S_max`, `M_max`, `TP`, `PLR`, climax delta, interior relative drops, `isSilentTrack`), decouples `expectSchema` (default `3` on built-in `v4`) from `upgradeBelow` (`--upgrade-below`), exports 0-token `probeAudioBackfill` (`--probe-audio-only`), writes artifacts atomically, and cleans temp dirs & Chrome tabs in `finally` |

| `scripts/cli.ts` | Unified CLI exposing `collect` (`--backfill-timing`), `mine` (float `--fps 0.2..24`, `--auto-fps`, `--with-thumbnail`/`--no-thumbnail`, `--expect-schema`, `--upgrade-below`, `--min-schema`, `--probe-audio-only`), `validate` (auto-reads sibling `meta.json` FPS/audio/duration), `aggregate`, and `status` (`statsVersion === CURRENT_STATS_VERSION`, audio/`shortTermSampleN`/`transcriptTiming`/`activeSpeechSampleN` staleness checks, exit `1` on 0-mined halts, `2` on usage errors) |
| `scripts/channel-dna.test.ts` | Mutation-resistant TDD suite covering 3-way Taxonomy byte parity, 2-way `v3` enum parity with `learn-channel-video.md`, `v1`/`v2`/`v3` validation & coherence, Fisher/Mann-Whitney U/BH-FDR math, overlap-cleaned active-span transcript timing, 10 Hz FFmpeg loudness & silent-track exclusion, `shot-spine.ts` (`editTakeDurationEnvelope`, MW-U `dominantCraftMix`, `/occlu[ds]/`, `continuousBridgeMechanisms`, `hardCutMechanisms`), pre-flight 1M token guard, `macroOutputFps` downsampling, thumbnail gating, `gemini-api.ts` SSE `finishReason` & standalone CLI, and CLI exit/status contracts |

The Gemini API runner backs off on generation HTTP/SSE 503 and stops a key-pool invocation after five such responses. Its deadline bounds uploads, polling, generation and backoff. Remote cleanup has a separate time limit. The API and AI Studio share metadata and token rules from `scripts/review/gemini-video-input.ts`.

## Per-Channel Corpus Storage Layout

Every channel stores its raw catalog, checkpoints, validated dossiers, and aggregated stats inside its own skill directory at `.claude/skills/<channel-slug>/references/corpus/` so future AI sessions immediately see exact sample counts and resume state.

| File or Folder | Contents |
| --- | --- |
| `catalog.json` | Timestamped channel snapshot with views, likes, optional commentCount/commentRate/commentToLikeRatio/dimensions/sourceFps/thumbnailUrl/detectedLanguage/chapters/heatmap, durationSec, uploadDate, wordCount, wpm, overlap-cleaned `transcriptTiming`, `transcriptLangsTried`, `outlierRolling`, `outlierGlobal`, and performance tier |
| `queue.json` | Unmined video IDs interleaved across Winner, Flop, and Median tiers so every `--limit N` batch stays balanced |
| `checkpoint.json` | Per-video done or failed status, runner `chatUrl`/job URL, attempt count, and failure reason, written atomically after every video |
| `videos/<id>/dossier.md` | Complete 4-section Markdown analysis produced by Gemini that passed `schema.ts` validation |
| `videos/<id>/telemetry.json` | Parsed and validated structured telemetry JSON (`schema_version: 1`, `2`, or `3`) extracted from Section 4 of `dossier.md` |
| `videos/<id>/meta.json` | Combined performance metadata (views, outlier scores, tier, WPM), `miningMode` (`micro_24fps` vs `macro_lowfps`), optional media/audio telemetry (`sourceFps`, `sourceWidth`, `sourceHeight`, 10 Hz `audioMetrics`), and run provenance |
| `stats.json` | Full machine-readable deterministic `statsVersion: 4` statistics emitted by `scripts/aggregate.ts` |
| `stats-summary.md` | Concise human-and-AI statistical overview with explicit sample denominators and BH-FDR `p (q)` per layer (zero bold/backticks) |

## Multi-Day Checkpointing and Data Safety

| Failure Mode | Protection Mechanism |
| --- | --- |
| Interruption mid-collection | Writes `catalog.json` atomically (`.tmp` then rename) after every 10 enriched metadata items or 15 transcripts; re-running skips already-fetched records while recovering stale `""` transcripts when `--lang` changes (`transcriptLangsTried`) |
| Quota exhaustion, AI Studio `"signed out"`, Gemini API auth (`401`/`403`/invalid key), YouTube bot-gate (`403` / `"not a bot"`), or persistent 24 FPS/audio downgrade mid-mining | Commits `checkpoint.json` after each completed video, halts all workers cleanly via `shouldHaltBatch` (`haltReason`: `"quota"`, `"bot_or_auth"`, or `"media_downgrade"`) without marking blocked videos `failed` (allowing 1 isolated `>=45s` `AUDIO_UNAVAILABLE` clip to fail without aborting the queue unless a 2nd consecutive clip fails), and closes AI Studio worker Chrome tabs cleanly |
| Longform clip exceeding 1M context window (`> ~136s` at 24fps High) | `resolveMiningFps` checks estimated unified tokens BEFORE `yt-dlp` download and again after `ffprobe`; either auto-scales FPS cleanly (`--auto-fps`, tagging `miningMode: "macro_lowfps"`) or fails fast with an exact `--fps` suggestion |
| Transient CDP drop or Chrome restart leaving AI Studio tab generating or reset to `/library` | `executeAskAttempt` sets `submittedOnTab = true` ONLY when the current video reached `run` without a terminal AI Studio abort, recovers in-flight answers via `--collect`, drains leftover orphan generations safely into temp files, and falls straight through to fresh `runNew` on Chrome restart |
| Silent or missing audio stream on downloaded clip | Probes `hasAudioStream` during `burnTimecode720` (excluding `hasAudioStream === false` clips from audio-dependent VLM distributions and craft signals) and flags `isSilentTrack: true` (`<= -69.5 LUFS` or `-inf` true peak), excluding silent tracks from FFmpeg loudness medians |
| Degraded model media delivery (sparse 1fps stills or dropped audio track) or truncated output | Both transports verify delivered video tokens against the requested FPS + resolution floor, `gemini-api.ts` streams SSE and fails closed on `MAX_TOKENS`/safety blocks, `mine.ts` injects `INPUT_INCOMPLETE` sentinels, and `schema.ts` rejects `INPUT_INCOMPLETE:` markers, full-document 1fps/missing-audio disclosures, and repeated `>=15f` non-transition Boundary brackets |
| Truncated or malformed Gemini JSON | Saves raw failed output to `videos/<id>/raw-failed-a1.md`, retries once automatically, preserves prior valid dossiers when upgrading via `--upgrade-below 3`, and only writes `dossier.md` / `telemetry.json` when `parseAndValidateDossier` returns `valid = true` |
| Disk bloat from downloaded clips | Stores temporary downloads, thumbnails, and 720p timecode renders inside per-video `%TEMP%\cdna-<id>-*` folders deleted unconditionally inside `finally` |
