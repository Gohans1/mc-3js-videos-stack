# AI Studio TTS: Voice Casting, Direction & Production Guide

Empirically verified voice notes, prompting levers, tag hygiene, and production pitfalls for Google AI Studio Generate Speech (`gemini-3.8-flash-tts` — never fall back to `gemini-3.8-flash-lite-tts`), combining Google's official 3.8 TTS Developer Guide with live session audits. Treat these as tested starting points and guardrails—not a closed voice list. Audition freely, explore the 2,000+ Extended Voice Library, or use Voice Design / Remix when a film calls for a different character.

For the dedicated, empirically benchmarked **Zack D. Films** YouTube Shorts voice pack (50-video acoustic DNA, drop-in JSON templates, and broadcast post-chain), see [the Zack D. Films voice system](zack-d-films/README.md).

### Beyond the Audited Shortlist

- **Dual US catalog in `gemini-3.8-flash-tts` (`70` US voices):** Filtering `Language = "English (US)"` surfaces **40 new 3.8 catalog voices** (`Fola`, `Koda`, `Zeno`, `Cruz`, `Enzo`, `Rami`, `Ludo`, `Bodi`, etc.) **plus all 30 classic Gemini studio voices** (`Rasalgethi`, `Achird`, `Puck`, `Orus`, `Schedar`, `Iapetus`, `Fenrir`, `Charon`, etc. — `37` total under `English (US) + Masculine`: 21 new + 16 classic). By default each Use case group shows 3 preview voices behind `View all N`; filter by facet or search by name (`voices "<query>"`) to inspect all matching voices (`voices` has no `--all` flag).
- **Classic voice `sample --out` limitation:** `sample "<Name>" --out <path.wav>` exports public WAVs for the new 3.8 catalog voices, whereas classic voices play in-browser without exposing a downloadable catalog WAV (`"The voice played but exposed no new public catalog WAV"`). Audition classic voices with a short `speak` take instead.
- **Exact live filter labels:** Run `filter "<Facet>"` with no value first before selecting—live labels verified in 3.8 are `Language = "English (US)"`, `Gender = "Masculine" | "Feminine" | "Neutral"`, and `Pitch = "Low" | "Medium" | "High"` (guessing `"Male"` or `"English"` fails).
- **Extended Voice Library & Voice Design:** Over 2,000 regional accents/dialects via search/filters; `voice-create design/replication/remix` requires a linked paid billing key (see `SKILL.md`).
- **Casting against a reference track:** Measure the reference voice (`F0` median/spread, end-slope, warmth, WPM, pause median) **and** listen to it directly (`read_file` on WAV), screen candidates across both new 3.8 and classic voices, then run an apples-to-apples test take on real script lines before locking one voice.

## Directing Gemini 3.8 Flash TTS

Gemini 3.8 strictly separates **who**, **how**, and **what**. Never put stage directions inside `text` (unlike older 3.1 prompts); `text` is spoken verbatim except for `<vocal tags>`, `|backchannels|`, and `/IPA/`.

| Layer | Role | Practical Guidance |
| --- | --- | --- |
| `voices` | Identity / timbre | Pick a voice whose natural pitch and warmth already sit near your target—don't force a deep bass to act like a bright tenor. |
| `style` | Block-level acting & pace | Keep concise (~10–18 words): persona + pace + breath/pause cue + ending cadence. Test `style: ""` first as a baseline—3.8 already reads punctuation and context well. |
| `text` | Verbatim spoken script | Clean spoken English (or target language) with natural punctuation; place `<...>` tags and `|...|` only where a non-verbal event belongs. |
| `temperature` | Expressiveness vs stability | `0.60–0.70` for tight, consistent Shorts narration; `~0.75` for long-form documentaries needing melodic lift; `0.80+` for theatrical dialogue. |

### Style Levers & Traps Verified in Production

- **Keep `style` concise (~15–18 words) on `Rasalgethi`/`Puck`, and match energy cues to the voice**: On pure `gemini-3.8-flash-tts`, an over-stuffed 35-word `Goldilocks` directive stack caused halting, staged mid-clause pauses on `Rasalgethi` (`65.0/100` blind vs `84.0/100` for concise 17-word `R1_Natural` — a **`-19 pt` penalty**). Conversely, omitting `style` (`style: ""`) dropped `Rasalgethi` `F0` `-2.1 st` (`132 Hz`) and rushed pace (`210 WPM` raw), while `Zeno` specifically gained `+8.5 pts` from `S3_Urgent` (`84.5`) over `R1_Natural` (`76.0`).
- **Avoid `"deadpan"` in `style` when you need a higher/energetic register**: Across controlled pure `gemini-3.8-flash-tts` ablations, adding `"deadpan"` dropped median `F0` by **`3.5–4.8 semitones`** (`Rasalgethi`: down to `110.0–121.8 Hz`; `Zeno`: down to `117.6 Hz`). Use **`"dry, fascinated"`** or **`"clear, curious"`** instead.
- **Avoid `"YouTube Shorts"` / `"Shorts"` in `style` when you want crisp normal pace**: Including `"YouTube Shorts"` or `"Shorts"` accelerated pacing (`Koda` `182–190 WPM`, `Rasalgethi` `-2.15s` faster & thinner `80–250 Hz` warmth). Use `"steady conversational pace"` or `"steady brisk conversational pace"` for crisp articulation.
- **Watch `temperature >= 0.75` on fast Shorts & stochastic take-to-take `F0` variance**: Raising `Rasalgethi` from `t=0.65` (`84.0`, Articulation `88.5`) to `t=0.75` (`67.0`, Articulation `56.0`) on pure `gemini-3.8-flash-tts` triggered a clear `"steadily"` → `"stedery"` L→R consonant slur (`-17 pts`). Also expect natural `±8–15 Hz` (`±1–1.5 st`) take-to-take `F0` variance on identical settings — generate 2 quick takes via `--backend api` (~6s each) and pick the cleaner/brighter take by ear.
- **Never trust acoustic stats alone**: Acoustic summaries (`F0`, `mfccCos`) miss fast `<260 ms` audible inhales (`Achird` ranked #1 acoustically at `149.2 Hz` yet #5 by ear at `71.0` due to loud breaths) and halting phrasing (`Goldilocks`). Always audition takes via `read_file` on WAV.
- **Kill AI uptalk on endings**: Phrases such as `"flat matter-of-fact endings"` or `"clean downward declarative endings"` prevent rising ad-read cadence at the end of declarative statements.
- **Shift tone mid-scene with multiple blocks**: Instead of cramming conflicting moods into one long `style`, split consecutive turns for the same speaker (e.g., hushed whisper → sudden shout → out-of-breath calm) so each block gets its own `style`. Assign the same voice to both slots (`"voices": ["Cruz", "Cruz"]`) when using multiple blocks for one narrator.
- **Prefer short 5–10 word `style` cues and know Gemini 3.8's per-word limits**: Per Google's official Gemini 3.8 TTS Prompting Guide, short direct style cues beat long `"Audio Profile"` persona essays. `text` is strictly verbatim: Gemini 3.8 has **no SSML (`<prosody pitch>`) and no inline tags to shift pitch/weight on a single word** (inline `<...>` tags are vocal events/pauses only), and ALL-CAPS or stretched-letter hacks (`THÍNKkk`, `dreamìnggggg`) do not reliably control syllable melody. If you need 1:1 syllable-by-syllable prosody transfer from a reference recording, use Speech-to-Speech (`voice:playground` Voice Changer) rather than fighting TTS text prompts.
- **Example starting styles (adapt freely)**:
  - *Channel-locked Zack-style Short (`Rasalgethi` on `flash-tts`, primary default `m1_steady_story`, `~160–185 WPM` post)*: `"calm, matter-of-fact storytelling, unhurried steady pace, falling endings"` (`temperature: 0.65`, see [zack-d-films/README.md](zack-d-films/README.md)).
  - *Brighter/faster Zack D. Films Short (`Rasalgethi` `R1_Natural`, `~167–214 WPM` post across 5 genres)*: `"Clear, curious American explainer narrator, steady conversational pace, crisp articulation, short natural breaths, clean downward declarative endings"` (`temperature: 0.65`).
  - *High-punch urgent Short (`Zeno` on `flash-tts`, `~181–230 WPM` post)*: `"Fast, crisp, close-mic American male storyteller, dry fascinated urgency, sharp vocal pops on key nouns, tight jump-cut pacing, zero breathiness, firm falling sentence ends"` (`temperature: 0.70`).
  - *Engaging long-form documentary (`Cruz` on `flash-tts`, ~140 WPM spoken)*: `"Speaking briskly, crisp engaging YouTube documentary narrator, tight pauses, close-mic studio clarity, curious lift on questions, grounded punch on key facts"` (`temperature: 0.75`, see Long-Form Blueprint below).

## Inline Vocal Tags, Backchannels & Script Hygiene

- **Vocal tags (`<...>`)**: Always write tags in **English** even for non-English scripts (`<gasp>`, `<sigh>`, `<laugh>`, `<chuckle>`, `<cough>`, `<short pause>`, `<pause>`). Tags trigger once at the exact word position rather than coloring the whole block.
- **Skip `<short pause>` in tight narration/documentaries**: Sprinkling `<short pause>` tags + em-dashes stretched a 50-word documentary test clip by `+3s` (`18.6s -> 21.5s`) and broke conversational momentum. Use plain punctuation (`.` `,`) for natural micro-rhythm and shape longer scene pauses via timeline **Phrase Bricks** instead. Reserve `<...>` tags for expressive acting where the non-verbal sound genuinely belongs.
- **Two-speaker `|backchannel|` pipes**: In two-speaker scenes, wrapping 1–3 words in pipes (`|mhm|`, `|wait, what?|`, `|no way|`) inside Speaker 1's `text` has Speaker 2 overlap naturally without slicing the line into extra turns.
- **Spell numbers, years & acronyms for speech**: Keep display formatting in captions (`GTA 6`, `99`, `2013`, `3D`), but write clean spoken forms in TTS `text` (`GTA six`, `ninety-nine`, `twenty thirteen`, `three-D`).
- **Fix pronunciation via phonetics or `/IPA/`**: For tricky proper nouns or names, either spell phonetically (`Leoneeda`) or use Gemini 3.8's native `/IPA/` syntax (`/liːəˈniːdə/`).
- **Rewrite fast-speech slurs heard on playback**: If a clean phrase blurs at speed (e.g., `"a clinic lay"` sounding like `"clinically"`, or `"rowboat"` sounding like `"robot"`), swap to cleaner words (`"a hospital sat"`, `"a small boat"`) and regenerate rather than trying to EQ around it.

## Generation Strategy & QA Guardrails

- **Shorts (`<= 60s`) — one contiguous pass**: Generate the full narration in a single block so timbre, pitch floor, and room breath stay seamless across every sentence. Align with WhisperX, then slice at true silent troughs (`<= -70 dBFS`) into scene-aligned Phrase Bricks at `rate: 1.0`. Only use formant-preserving Rubber Band R3 within `<= ±5%` when strictly needed.
- **Long-form (`> 60s`) — beat-anchored takes**: Split by scene beats, freeze one invariant `style` + `temperature` across all takes, and use `TTS --tab tts-batch batch manifest.json` to reuse one tab and voice setup in a single process. If a take overruns its slot by `>5–6%`, trim/tighten the script and regenerate instead of aggressively time-stretching.
- **Always listen directly to exported WAVs**: Inspect takes and the final mix directly (`read_file` on WAV). WhisperX logs and `earshot` numbers alone miss subtle mispronunciations and mid-word tail cutoffs.
- **Daily free-tier RPD quota — use `--backend api`, NEVER fall back to `gemini-3.8-flash-lite-tts`**: Always run full **`gemini-3.8-flash-tts` + concise `style` (~15–18 words, `t=0.65`)** for realistic human prosody and organic emphasis. `gemini-3.8-flash-lite-tts` produces noticeably flatter, less human delivery and is **banned** (rejected by `cli.ts` on both `web` and `api` backends). If AI Studio web hits its daily free-tier RPD limit, switch to **`--backend api`** (`TTS --backend api speak|batch ...`) to run the same `scene.json` / `manifest.json` through the rotating `~/.config/gmn` Gemini API key pool (`GEMINI_API_KEY` fallback); if all API keys are also exhausted, **STOP and report the quota exhaustion to the user immediately**.
- **Tighten raw TTS breath gaps safely for Shorts**: Raw AI Studio TTS leaves audible `300–550 ms` breath intakes between sentences. Tightening oversized gaps (`>260 ms` -> `~185 ms`) while preserving `>= 95 ms` post-word sibilant tails (`-s`, `-z`, `-t`) and applying 2-pass linear broadcast EQ/compression (`-14 LUFS`, `-1.5 dBTP`) added `+27.0` polish (`48 -> 75`) and `+5.0` overall (`60.0 -> 65.0`) points on the identical pure `gemini-3.8-flash-tts` recording in controlled blind tests (see [zack-d-films/post-process.py](zack-d-films/post-process.py)).
- **Protect word tails**: Never run aggressive silence-tail trimming (`trimTail`) without checking the final ~300ms RMS; keep `>= 90–95 ms` post-word tail buffers and apply `15–20 ms` cosine fades on splices so final sibilants never clip.
- **Windows CLI & CDP concurrency stability**: Prefer `speak` / `batch` (single Bun process) so Chrome stays inside one Windows `exebox` session, keep **total active Chrome tabs `<= 2`** across all sessions, run **one TTS `batch`/`speak` tab at a time** (concurrent batches serialize over shared CDP port `9333` and stall `update screenplay` from `~2s` to `400s+`), and avoid launching heavy CPU WhisperX jobs concurrently with active CDP calls (see `SKILL.md` for `--keepalive`).
