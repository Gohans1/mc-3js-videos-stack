## 2. 3-Tier Policy: Hard Stops vs Craft Guardrails vs Empirical Norms

Never confuse a non-negotiable integrity/physics failure with a channel guardrail or a flexible preference:

- **Tier 1 — Integrity & Physics Hard Stops (Non-Negotiable — Never Waive):** Fact/Premise honesty (`A3`), beat `%` sum = `100%` (`A4`), zero exclamations / fourth-wall camera leaks / AI-slop / filler / moralizing endings (`A4b`), protected semantic hues & Google 9:16 Safe Box clearance (`A7`, `B1`), zero render artifacts (`B1–B4`), ITU-R BT.1359 SFX sync, and linear EBU R128 / true-peak / dual-mono / phase mastering safety (`A9`, `B5`).
- **Tier 2 — Channel Craft Guardrails (Never Auto-Waive — Push Back Once):** `but_therefore`/`causal_chain` causality (`A4`), character or POV inside a bounded world (`A2`), non-imperative / zero `"you see"` rewind opening (`A2`, `A4b`), `<180` WPM intelligibility ceiling (`A5`), `<=1` Hard Cut (`A6`), and clinical calm VO + continuous emotion-matched BGM (`A9`). Push back concretely once with empirical evidence; if the user still explicitly insists, log **`OVERRIDE (Intentional — Risk Acknowledged)`** and run the 5-surface ripple sweep.
- **Tier 3 — Empirical Norms (Freely Overridable With Consent):** Target runtime (`35–44s` vs `55–64s` or intentional short punch), emoji style, Title opener archetype, specific transition flavor (`card_flip` vs `push_up` vs pure continuous showcase), or lighting mood for a deliberately dark/horror concept. Record **`OVERRIDE (Intentional — User Choice)`** and trace upstream/downstream ripples cleanly.
- **English-First Default (Cleanly Extensible):** Default video output language is **English** (ZDF's native language). If the user explicitly asks for another output language later, strictly enforce all **Language-Universal Soul** gates (runtime, beat `%`, visual-to-VO separation, Dual-Path confirmation, burstiness `CV >= 0.28` / `max/min >= 2.0x`, `<=50` mobile display-unit title ceiling, camera/edit/optical/audio grammar) and mark English-only surface metrics (`FK Grade`, EN space-separated WPM/title word counts, EN contractions/starters) **`PASS (Language-Adapted)`** using syllable/mora tempo (`3.2–3.8` syl/s, `<4.3` ceiling).

### 3-Step Original-Video Stage B QA Protocol

> **Critical Scope Rule:** **NEVER run `compare-video` (or any 1:1 reference-ranking sweep) on an original Short that has no 1:1 `REF` video.** `compare-video` grades 1:1 remake parity against a reference source; running it on an original video produces nonsense penalties. Use the 3-step original-video workflow below instead:

1. **Step 1 — Deterministic Local Ground Truth (`0` AI tokens):**
   - Run all exact FFmpeg loudness, linear `loudnorm`, `aformat=channel_layouts=stereo,` dual-mono fold-down, and `aphasemeter` commands in [audio-voice-and-pacing.md §4](audio-voice-and-pacing.md#4-itu-r-bt1359-sfx-sync-4-tier-gain-ladder-mobile-hygiene--linear-ebu-r128-mastering) on the final muxed `final.mp4` (confirm `-14 LUFS ±1.0`, `<= -1.0 dBTP`, `S_max <= I + 3.0 LU`, post-encode `PLR 8–13 dB`, Pass 2 `"normalization_type": "linear"`, zero dead digital silence, dual-mono `<=2.5 LU`, and `aphasemeter` mean `>= +0.25`).
   - Extract and inspect 3-state emissive stills (`pre-ON`, `peak-ON`, `post-OFF`, `PL-003`), transition/hidden-cut boundary stills, 9:16 Safe Box / text clearance stills, grayscale `>=20%` value/silhouette & shadow/bloom/cutaway/wardrobe checks, and mute/blind-audio checks *(for optional local `mc-films` commands, `earshot`, and Studio Director's Eye shortcuts, see [animation-lookdev-and-vfx.md §7.1](animation-lookdev-and-vfx.md#71-optional-local-adapter-minecraft-3d--mc-films-monorepo))*.
2. **Step 2 — Optional Consent-Gated Visual Soul Audit:**
   - **Explicit User Consent First (Every Round):** Never spend external multimodal API quota unsolicited — confirm with the user before Round 1 AND re-confirm before launching Round 2.
   - Package the finished render with the [single-source stills recipe](../../compare-video/references/stills-field-audit.md#single-source-stills) at 15 fps, with up to 450 JPEGs per list.    - **Mandatory Native-FPS Local Triage, `B6 Verified PASS & STOP`, & 2-Round Stall Circuit Breaker:** Never trust VLM flags blindly — verify every flagged defect on native-FPS extracted frames and classify it under the **3-Tier Policy**:
     - **`Verified Defect` (Must Fix):** Any native-FPS-verified **Tier-1 Hard Stop** breach, **un-overridden Tier-2 Guardrail** breach, or concrete render, continuity, or story blocker.
     - **`Dismissed` (Do Not Chase):** VLM false positives disproved on native-FPS frames, **Tier-3 Empirical Norms**, or items carrying an explicit Stage A **`OVERRIDE`**.
