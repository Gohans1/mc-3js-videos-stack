## Data Provenance & Exact Denominators (`statsVersion: 4`)

Never blend denominators across layers. Winner-vs-Flop spreads in a tier-stratified corpus are **observational prioritization signals**, not proof of direct causation. Both raw `p` (Fisher exact or cluster-valid equal-weight Mann-Whitney U) and Benjamini-Hochberg FDR `q` are reported (`q < 0.05` marks corpus-wide high-confidence laws ★); reliability tiers: `stable` (`n >= 8`), `tentative` (`n = 5–7`), `directional` (`n < 5`).

## Top 10 Channel Soul Laws (3-Tier Policy: Hard Stop > Guardrail > Norm)

Apply the exact same **3-Tier Policy** as [references/anti-patterns-and-qa.md §2](references/anti-patterns-and-qa.md#2-3-tier-policy-hard-stops-vs-craft-guardrails-vs-empirical-norms): **`[Hard Stop]`** (Integrity/Physics — non-negotiable), **`[Guardrail]`** (Channel Craft Guardrail — never auto-waive; push back once with evidence, allow `OVERRIDE (Intentional — Risk Acknowledged)` only if user still insists), and **`[Norm]`** (Empirical Norm — freely overridable with `OVERRIDE (Intentional — User Choice)`):

1. **[Guardrail | `q=0.086`] Cause-and-Effect Chain (`100%` of Winners, `N=62`):** Every Winner (`25/25`) uses `but_therefore` (`56%`) or `causal_chain` (`44%`); `chronological_and_then` sits at `0% W` vs `21.1% F` (`p=0.029`). Stacked multi-escalation/twist loops appear in `24% W` vs `0% F` (`p=0.029, q=0.144`).
2. **[Guardrail | `q=0.019` ★] Character or POV Inside a Bounded World (`100%` of Winners, `N=62`):** Winners use `third_person_characters` (`88% W` vs `57.9% F`, `p=0.035`) or `first_person_pov` (`12% W` vs `0% F`). `faceless_objects_diagrams` hits `0% W` vs `31.6% F` (**`p=0.004, q=0.019`**), and floating vignetted voids in explainers score `25% W` vs `100% F` (`p=0.033, q=0.812`).
3. **[Hard Stop / Guardrail] Zero 4th-Wall/Slop/Narrator Exclamations (`[Hard Stop]`); No DIY Commands or `"You See"` Rewinds (`[Guardrail]`):** `0%` narrator VO exclamations (`0/50`), `0%` formal AI connectors, `0%` AI-slop buzzwords, `0%` filler intros, `0%` moralizing endings, `0%` meta-camera leaks (*"camera path"*, *"from above"*); `imperative_how_to_step` hits `4% W` vs `31.6% F` (`p=0.032`) and `"you see"` rewinds hit `9.1% W` vs `41.7% F`. 4. **[Norm] Bursty Spoken-Saxon Prose, Zero Redundancy & Organic Callback (`N=50` clean):** Real ZDF scripts average `6` multi-clause sentences (`15w` median, `S1 18w`, final `17.5w`, `0%` per-video `<=8w` median), Grade `6.7` (`94.5%` `<=2`-syllable, `56%` contractions), locked POV (`4.1%` mid-script shifts), spoken starters (`45%`), bare-pronoun S1 openers (`34%`), trailing participle tails (`59.1% W` vs `33.3% F`), **`60%` S1/Title-to-closing echo**, and real **per-video burstiness (`CV = 0.36 W` vs `0.31 F`, `9.5..26w`, `2.76x` ratio, `6.3w` adj jump)**. ### Mode A — Interactive Soul Co-Creation (3 Stop-and-Wait Gates)

**Showrunner Rules:** (a) **User-Spark Lock** — protect the user's core premise, twist, or emotional spark; never sand it into a generic cliché. (b) **Productive Tension & 3-Tier Policy** — never waive a `[Hard Stop]`; push back once with empirical evidence on `[Guardrail]` breaches (logging `OVERRIDE (Intentional — Risk Acknowledged)` only if the user still insists); accept `[Norm]` overrides cleanly (`OVERRIDE (Intentional — User Choice)`). (c) **Mid-Session 5-Surface Ripple Sync** — whenever the user pivots premise, tone, twist, target language, or visual style mid-session, re-sync all 5 surfaces in order before proceeding: `1. Title & Hook -> 2. Beat Budgets & Script -> 3. Shot/Camera/Transitions -> 4. Audio/VO/SFX -> 5. Asset Manifest & Scorecard`.

1. **Gate 1 — Premise Stress-Test, Fact Lock & 3 Orthogonal Pitches (STOP & WAIT):**
   - Run the **4-Point Premise Stress-Test** & **3-Check Frame-0 Scroll-Stop Gate** ([hooks-and-openings.md §1.1](references/hooks-and-openings.md#11-zdf-premise-stress-test--reframe-engine-run-at-mode-a-gate-1)) + `10–20%` Second Decision check. Route via `Hook/Story/Ending x Topic` & `withinBucketContrasts` (`[directional -> mechanism fallback]` if `n < 5`).
   - Run **Fact / Premise Lock** (1–3 verified factual claims or explicit hypothetical/visual-experiment rules).
   - **English-First Default (Cleanly Extensible):** Reply in the user's conversation language, while defaulting video scripts/titles to **English** (ZDF's native language) and core visual style to engine-agnostic native craft unless the user explicitly asks for another output language or an adapter (`mc-films` §7.1). If another output language is explicitly requested later, keep Language-Universal Soul intact and mark EN-only surface metrics `PASS (Language-Adapted)`.
   - Pitch **3 Orthogonal Angles** (`Title + Emoji | Frame-0 Visual | Opening Spoken Line | Core Twist/Payoff`): **(1) Bullseye** (highest empirical fit), **(2) POV / Hook Flip** (fresh perspective or hook archetype), **(3) Wildcard** (bold creative swing). **Stop and wait.**
2. **Gate 2 — Beat-Budgeted Verbatim Script, Clean-Read VO Block & Stage A Script Audit (STOP & WAIT):**
   - Draft `5–8` bursty spoken-Saxon sentences (`35–44s` default, `145–165` WPM, `CV ~0.30–0.45`, locked tense & POV, zero visual-dressing redundancy, Causal-Necessity & `[PLANT]`/`[PAYOFF]` withholding, `0` narrator exclamations/4th-wall leaks/AI-slop/rewinds, Dual-Path Confirmation, compact `setup <=15%` on `cold_open_crisis`, escalation before explanation on `visual_pattern_interrupt`, `2–3` re-hooks spaced `~8–10s`, late twist `65–80%`, concrete closing organically echoing S1/Title).
   - Output a **Clean-Read VO / TTS Block** (plain spoken text with phonetic spellings for acronyms/numbers and zero stage directions) + **Stage A Script Scorecard (`A1–A5` + `A9` Voice/TTS/BGM/Master Plan; `A6–A8` & shot-bound `A9` SFX marked `Pending Gate 3`)**. **Stop and wait.**
3. **Gate 3 — Persisted Synced Blueprint, `[Word/Event Anchor]` Manifest & `VO-Locked` Bridge:**
   - Persist the final blueprint (`BLUEPRINT.md` in the film directory when building a real film) containing:
     1. **Audio-First Re-Timing (`Pre-VO Projections` -> `VO-Locked`):** Label all draft timestamps `Pre-VO Projections` and bind every key visual/VFX/SFX cue to `[@word "..." ±f | proj XX.XXs]` anchors so aligning real VO mechanically promotes the blueprint to `VO-Locked` (`PL-006`).
     2. **6-Rule Cross-Department Beat Sync Table:** Clean-Read VO / TTS Block, `VO Cue & [Sync Anchor]`, whip/motion direction + eye-trace continuity, Google 9:16 Safe Box (`x: 4.4–82.2%`, `y: 15–65%`), measured transition spans (`0.17s`/`0.23s`), protected semantic hues (`FN-005`), and `MCU/CU eye` close + `0.7s` tail.
     3. **Compact 6-Row Asset & Cue Manifest:** Characters/Rigs, Bounded Environments, Hero Props & Cutaways, Graphics/Captions/Protected Hues, Voice Prosody + BGM Bed, and `[Word/Event Anchor]` Synced SFX Cues (with gain tier).
     4. Optional Target-Style Adapter ONLY if requested (e.g., `mc-films` `### 7.1`). Finish with Stage A (`A1–A9`) verified + Stage B (`B1–B6`) pending.

### Mode B — Direct End-to-End Blueprint
Execute Gate 1 (Premise Stress-Test + Fact Lock), Gate 2 (Verbatim Bursty Script + Clean-Read VO Block), and Gate 3 (Synced Blueprint + `[Word/Event Anchor]` 6-Row Asset/Cue Manifest + `Pre-VO Projections` + Stage A/B Scorecard) in one clean pass.
